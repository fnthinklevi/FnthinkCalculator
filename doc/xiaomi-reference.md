## 0. 适用范围与优先级

### 0.1 适用范围

本文件约束以下内容：

- 应用全局框架、导航、主题、颜色、字号、间距、圆角、动效。
- 计算器（标准/科学）、显示区、历史记录、设置。
- 换算首页与全部换算/工具页：汇率、时间计算、长度、重量、面积、体积、温度、速度、时间转换、进制、大写数字、称呼、BMI、个税、房贷、时差计算。
- 所有输入、键盘、选择器、结果页、错误态、空态、深色模式。
- 测试、验收、命名、文档与提交规则。

### 0.2 优先级

发生冲突时按以下顺序执行：

1. 产品硬约束（见第 1 节）。
2. 本文件的界面/交互/算法标准。
3. `doc/base.md` 中的技术基线。
4. 现有实现与历史测试。

### 0.3 变更流程

任何界面或交互变更必须按顺序完成：

1. 先修改本文件（含版本号、变更记录）。
2. 再修改实现。
3. 同步更新受影响测试、golden、冒烟记录。
4. 更新 `doc/base.md` / `doc/roadmap.md` 中的对应状态。
5. 本地提交；未经明确授权不得 push。

## 1. 产品与复刻硬约束

以下规则不可通过普通任务改动，必须单独立项：

1. **顶部只有两个标签：`计算` / `换算`**。不设第三个“多功能”标签。
2. 原“多功能”内容全部并入换算首页图标网格：房贷计算、大写数字、时间五个独立页（日期差/日期推算/时间计算/时差计算/年龄计算）均从换算首页进入。
3. 换算首页最终包含 14 个对标工具 + 6 个自有工具（时间五页、比例计算），共 20 个入口；不得保留未实现的空入口。时间计算入口固定在第一行靠前位置。
4. **计算器与换算工具使用自绘内置键盘；表单页（个税/房贷/BMI/比例）按小米口径使用系统数字键盘**。`lib/` 内仅 `number_form_field.dart` 与这四个表单页允许 `TextField`；日期/时间选择仍可使用系统日历/时钟。
5. 不使用小米的任何素材与字体；不接入小米/东方财富/微牛的数据接口。
6. 数据必须如实标注来源；不得伪造城市税率、汇率或更新时间。
7. 无广告、无统计、无用户数据上传；汇率是唯一联网功能。
8. 中文界面；深色模式跟随系统，并允许手动覆盖。
9. 横屏与平板必须可用；布局按第 3、4 节的约束自适应，不得出现溢出。
10. 所有新功能必须同时具备：入口、内置键盘输入、错误态、空态、深色适配、测试、冒烟记录。

### 2.3 几何与间距

物理像素按 420 dpi 换算（约 2.625 px/dp）：

| 元素 | 物理尺寸（实测） | 逻辑尺寸（约） |
|---|---|---|
| 标准圆键直径 | 204 px | 78 dp |
| 标准键盘间距 | 34 px | 13 dp |
| 标准键盘左右边距 | 80 px | 30.5 dp |
| 科学圆键直径 | 156 px | 59 dp |
| 换算圆键直径 | 214 px | 81.5 dp |
| 换算键盘间距 | 26 px | 10 dp |
| 竖长键（C/⌫/±） | 211×449 px | 80×171 dp |
| 顶栏高度 | 147 px（含状态栏外的 56 dp） | 56 dp |
| 顶栏胶囊 | 约 410×110 px | 156×42 dp |
| 胶囊选中段 | 约 250×96 px | 95×36 dp |
| 标准键盘 5 行总高 | 5×204 + 4×34 = 1156 px | 440 dp |
| 科学键盘 7 行总高 | 7×156 + 6×34 = 1296 px | 494 dp |
| 主按钮高度 | 131 px | 50 dp |
| 主按钮左右边距 | 73 px | 28 dp |
| 表单行高 | 约 169 px | 64 dp |
| 换算图标网格 | 3 列，单元格约 275×363 px | 105×138 dp |
| 结果页英雄卡圆角 | 40 px | 15 dp |

实现公式：

- 标准键盘圆径 = `min((可用宽 - 2×30.5 - 3×13) / 4, (可用高 - 4×13) / 5)`，上限 80 dp。
- 科学键盘圆径 = `min((可用宽 - 2×30.5 - 4×13) / 5, (可用高 - 6×13) / 7)`，上限 64 dp。
- 换算键盘圆径 = `min((可用宽 - 2×28 - 3×10) / 4, (可用高 - 4×10) / 5)`，上限 82 dp。
- 圆键在单元格内居中；不得用圆角矩形替代圆键（竖长键除外）。
- 所有可点击区域不小于 44×44 dp。

### 2.4 动效与触感

- 按键按下：缩放至 0.94，80 ms；松开回弹。
- 顶栏标签切换：160 ms 背景与字重过渡。
- 页面切换：系统 Material 页面过渡；二级页从右侧滑入。
- 选择器/菜单：系统 popup 动画；不使用全屏 bottom sheet（历史页、设置页除外）。
- 触感：按键轻触 `lightImpact`；顶栏切换/科学键 `selectionClick`；长按 `mediumImpact`；设置中可关闭。
- 不做多余动画、粒子、渐变背景（房贷结果卡除外）。

## 3. 全局框架

### 3.1 顶栏

```
[        计算 | 换算        ]                    ⋮
```

- 高度 56 dp；背景与页面一致；无分割线、无阴影。
- 胶囊：宽 156 dp、高 42 dp、圆角全圆；轨道白色（深色 `#1C1C1C`）；内边距 4 dp。
- 选中段：浅灰 `#F0F0F0`（深色 `#333333`）；文字 16 sp、w500、主文字色；未选中透明、w400。
- 两个标签等宽；点击切换，当前页保持状态（IndexedStack）。
- 右上 `⋮`：24×24 图标，距右 4 dp；点击弹出菜单：
  - `历史记录`：打开历史页。
  - `设置`：打开设置页。
- 首次启动在 `⋮` 下方显示一次气泡「在这里设置语音播报」；本产品已提供语音播报，但不在启动时弹气泡，统一在设置页开启。
- 菜单为白色圆角卡片（深色深灰），圆角 16 dp，每项高 48 dp，文字 16 sp。

### 3.2 二级页头部

- 高 56 dp；**容器必须整宽**（`width: double.infinity`），左侧返回箭头（`arrow_back_ios_new`，20 dp）固定在页面左边，标题居中 19–20 sp，w500；右侧动作图标 24 dp。禁止让标题宽度收缩容器，否则返回键会被标题覆盖。
- 标题文案严格按各页定义（如 `长度转换`、`历史记录`、`计算器`、`房贷清单`）。
- 页面背景与主页面一致；无 AppBar 阴影。

### 3.3 页面层级

- 根：`AppShell`（顶栏 + IndexedStack[计算页, 换算首页]）。
- 二级页：历史、设置、各换算页、各工具页、各结果页，均使用 `Navigator.push`。
- 结果页返回后保留表单输入与状态。
- 不设置底部导航栏。

## 4. 计算器页

### 4.1 标准键盘

固定 4 列 × 5 行，圆键，行序如下：

| 行 | 列 1 | 列 2 | 列 3 | 列 4 |
|---|---|---|---|---|
| 1 | `AC`/`C`（橙） | `%`（橙） | `÷`（橙） | `⌫`（橙） |
| 2 | `7` | `8` | `9` | `×`（橙） |
| 3 | `4` | `5` | `6` | `−`（橙） |
| 4 | `1` | `2` | `3` | `+`（橙） |
| 5 | `切换`（橙图标） | `0` | `.` | `=`（橙色实心圆、白字） |

规则：

- 无输入且输入模式：左上显示 `AC`；有输入或结果态显示 `C`。
- `C` 单击清空当前算式并回到输入态；长按弹出「清空历史记录」确认框（保留的增强操作）。
- `切换` 切到科学键盘；科学键盘左下角同一个键切回。
- `⌫` 在右上角，逐字符删除；结果态按 `⌫` 回到该结果的表达式继续编辑。
- 无 `±`、无 `00`、无括号。
- `%` 只作为后缀百分号，不能单独作为运算符。

### 4.2 科学键盘

固定 5 列 × 7 行，圆键，行序如下：

| 行 | 列 1 | 列 2 | 列 3 | 列 4 | 列 5 |
|---|---|---|---|---|---|
| 1 | `2nd` | `DEG`/`RAD` | `sin` | `cos` | `tan` |
| 2 | `xʸ` | `lg` | `ln` | `(` | `)` |
| 3 | `√x` | `C`/`AC`（橙） | `%`（橙） | `÷`（橙） | `⌫`（橙） |
| 4 | `x!` | `7` | `8` | `9` | `×`（橙） |
| 5 | `1/x` | `4` | `5` | `6` | `−`（橙） |
| 6 | `π` | `1` | `2` | `3` | `+`（橙） |

8. **历史写入**：每次按 `=` 写入一条，包括错误；最多 200 条；按时间倒序。
9. **历史带去重**：当前表达式与最新历史相同则不重复显示。

```
1   2   3   ⌫（竖长，跨 3–4 行）
00  0   .
```

- 规则：
  - `0` → `零圆整`；整数 → `壹仟贰佰叁拾肆圆整`；带角分 → `壹仟贰佰叁拾肆圆零伍分`。
  - 使用 `圆`（不是“元”）；整数后缀“整”；角位为零且分位非零时补“零”。
  - 负数不支持，输入负号无效。
  - 最大输入 15 位有效数字。
- 计算器长按菜单的“转换为大写数字”使用同一套规则。

## 12. 温度换算

- 标题 `温度转换`。
- 两行：摄氏度 °C / 华氏度 °F（可换开尔文、兰氏度、列氏度）。
- 键盘见 8.4.2；`±` 切换零上/零下。
- 公式：
  - C→F：`F = C×9/5 + 32`；F→C：`C = (F−32)×5/9`。
  - C→K：`K = C + 273.15`；K→C：`C = K − 273.15`。
  - C→R：`R = (C + 273.15)×9/5`；R→C：`C = R×5/9 − 273.15`。
  - C→Re：`Re = C×4/5`；Re→C：`C = Re×5/4`。
- 结果最多 2 位小数；负号正确；`-40 °C = -40 °F`。
- 验收：三点校验（0/100/-40），键盘无运算符，± 正确。

## 15. 个税计算

### 15.1 表单

- 标题 `个税计算`；顶部分段：`月薪` / `年终奖`。
- 月薪字段：
  - `税前收入（元）`：下划线输入，占位 `请输入您的税前收入`。
  - `缴纳期数`：默认 10；点击弹出 1–12 列表浮层（当前项橙色勾）。
  - `所在地`：点击打开 31 省级选择浮层（2025 社保年度静态表）；选中后显示省名，并按该省 2025 平均工资 × 个人费率 10.5% 估算五险一金（不含公积金，可手动修改）。数据来源为人社通公开汇总；只到省级，不伪造城市数据。
  - `专项附加扣除`：默认 `无`；点击弹出多选浮层（子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护），显示合计金额。
  - `五险一金（元）`：下划线输入，可直接输入合计；选择省份后自动填入估算值；下方提示数据年度、基数区间与“不含公积金”。
- 底部说明：`采用新个税法计算，数据仅供参考`（不得写“东方财富”）；橙色 `开始计算`。
- 年终奖：`税前年终奖（元）` + `缴纳期数`（可选）+ 计税方式说明；单独计税。
- 表单页使用系统数字键盘（与小米一致）；选择器不使用系统输入法。

### 15.2 计算口径

- 月度应纳税所得额 = 税前收入 − 5000 − 五险一金 − 专项附加扣除 − 其他依法扣除。
- 七级超额累进税率（月度）：
  - ≤3000：3%，速算扣除 0
  - 3000–12000：10%，210
  - 12000–25000：20%，1410
  - 25000–35000：25%，2660
  - 35000–55000：30%，4410
  - 55000–80000：35%，7160
  - >80000：45%，15160
- 应纳税额 = 应纳税所得额 × 税率 − 速算扣除数；小于 0 按 0。
- 税后收入 = 税前收入 − 五险一金 − 应纳税额。
- 年终奖：奖金 ÷ 12 查月度税率表确定税率与速算扣除数；应纳税额 = 奖金 × 税率 − 速算扣除数。
- 结果页：应纳税所得额、适用税率、速算扣除数、应纳税额、税后收入、五险一金与专项扣除明细；金额保留 2 位小数，千分位。
- 验收：0 税、税率分界点、专项扣除、五险一金、年终奖案例；深色模式；无系统键盘。

## 16. 房贷计算

### 16.1 表单

- 标题 `房贷计算`；分段：`商业贷款` / `公积金贷款` / `组合贷款`。
- 商业贷：
  - `贷款总额（万）`：下划线输入，占位 `请输入您的贷款总额`。
  - `还款方式`：`等额本息（每月等额还款）` / `等额本金（每月递减还款）`，浮层选择。
  - `商业贷款年数`：1–40 年列表浮层，显示 `N年（N×12个月）`。
  - `首次还款日期`：系统日期选择器，默认今天。
  - `利率标准`：`LPR` / `基准利率`。
  - `LPR`：数值输入，默认 3.5%，右侧 `%`。
  - `基点`：数值输入，默认 0，右侧 `‰`。
  - `贷款利率`：只读汇总 `3.5% + 0‰ = 3.5%`。
- 公积金贷：金额、年限、利率（基准 4.9%）。
- 组合贷：商业金额/年限/利率 + 公积金金额/年限/利率 + 共同还款方式/首次还款日期。
- 底部：`数据仅供参考` + 橙色 `开始计算`。
- 所有输入内置键盘；金额单位“万”，计算时 ×10000。

### 16.2 计算与结果

- 等额本息：月供 = P×r×(1+r)^n / ((1+r)^n−1)；逐期计算利息=剩余本金×r、本金=月供−利息；末期调平，保证本金总和等于 P。
- 等额本金：每月本金 = P/n；每月利息 = 剩余本金×r；月供递减。
- 月利率 r = 年利率/12；以分为单位四舍五入，末期调平。
- 结果页标题 `房贷清单`：
  - 橙色渐变英雄卡：`每月需还款` 大号橙色数值 + `元`；房子插画（可用 Material 图标/自绘）；三列汇总：`还款总额（万）`、`支付利息（万）`、`贷款总额（万）`。
  - `N年还款明细（元）`：按年时间轴；每年显示 `本年还款`、`本年利息`，右侧圆形展开箭头；展开显示每月还款/本金/利息（可选）。
  - 首年按实际期数（首次还款日到年末）。
- 验收：已知案例（100 万、40 年、3.5% 等额本息 → 月供约 3873.91）；本金求和等于贷款额；零利率、1 年/30 年边界；深色模式。

## 21. 数据与算法标准

### 21.1 单位换算

- 内部统一以国际单位（m、m²、m³、kg、K、m/s、s）为基准，使用双精度或十进制有理数；避免累积误差。
- 市制：1 尺 = 1/3 m；1 寸 = 1/30 m；1 丈 = 10/3 m；1 里 = 500 m；1 亩 = 666.6666667 m²；1 顷 = 100 亩；1 斤 = 0.5 kg；1 两 = 0.05 kg；1 钱 = 0.005 kg；1 担 = 50 kg。
- 英制：英寸 0.0254 m；英尺 0.3048 m；码 0.9144 m；英里 1609.344 m；海里 1852 m；英亩 4046.8564224 m²；磅 0.45359237 kg；盎司 0.028349523125 kg；英制加仑 4.54609 L；美制加仑 3.785411784 L。
- 结果最多 12 位有效数字；去掉末尾 0；整数加千分位。

### 21.2 汇率

- 基准 CNY；交叉汇率 = rate(a)/rate(b)。
- 缓存 12 小时；缓存键沿用 `fx.rates.v1`。
- 数据源：优先 `open.er-api.com`，失败回退 `frankfurter.app`；两者都不支持的小币种不得显示；页面可换币种列表以数据源实际返回为准。
- 离线时显示缓存并标注；无缓存显示错误；不得伪造。
- 结果最多 6 位小数。

### 21.3 百分数

见 4.5；默认“按数值”，设置可切“按比例”。

## 23. 已知边界与暂缓项

1. **语音播报**：使用内置 Edge TTS 单音短音频（48 个 MP3，约 157.5 KiB），离线播放；不依赖系统 TTS/MVS，不内置大模型。
2. **小米素材**：所有图标、插画、字体均不使用；仅用 Material/自绘。房贷房子插画可用简化自绘或图标替代。
3. **个税城市数据**：不接入小米/东方财富城市社保数据；内置 31 省 2025 社保基数静态表（人社通公开汇总），只到省级；五险一金按平均工资 × 10.5% 估算，不含公积金，用户可改。
4. **汇率数据源**：不接入微牛/东方财富；使用现有公开接口，来源文案如实。
5. **表单键盘**：个税/房贷/BMI/比例表单已按小米口径使用系统数字键盘；计算器与换算仍使用内置键盘。
6. **时间计算的“月”**：小米时间换算不提供“月”；本产品时间计算（日期工具）仍可按日历月，但时间换算不使用“月”。
7. **比例计算**：小米 17.3.9 无此入口；T14 已作为第 16 个自有入口实现（按比例分配 / 比例求值）。
8. **数字精度**：小米显示多达 20 位数字；本产品统一最多 12 位有效数字，避免不可读的长尾（属于明确的产品改进）。
9. **首次启动隐私弹窗**：小米有用户须知/权限弹窗；本产品不需要联网权限弹窗（汇率联网在首次使用时说明即可），不复制其隐私弹窗。
10. **历史错误条目**：小米会保存错误；本产品同样保存，便于回看。

## 14. 大屏与折叠屏适配

### 14.1 宽度上限与断点

- 换算首页网格按可用宽度切换列数：`<560dp` 3 列；`560–759dp` 4 列；`760–879dp` 5 列；`≥880dp` 6 列。

## 15. 时间计算键盘（自有）

- 4 列 × 5 行圆键；第一行顺序 `C / 00 / ± / ⌫`，退格位于右上角。
- 数字 7–9、4–6、1–3 按三列常规排列；加减号位于第 4 列第 2–3 行。
- 等号位于第 4 列第 4–5 行，竖向胶囊，高度 = `2 个圆键 + 1 个间距`。
- 第 5 行：`0` 位于左侧跨 2 格（横向胶囊，保持正常键高）；冒号位于第 3 格，单格圆键。
- 全局只保留一个退格键；冒号仍按 时 → 分 → 秒 循环，0/冒号的输入行为不变。
- 支持连续公式，按从左到右求值：如 `12:00 + 12:01 + 13:01 = 1天 13:02:00`；出结果后再按运算符，从结果继续累计。
- 时差计算使用系统时钟选择开始/结束时刻，不使用此键盘。
- 布局与连续输入由 `test/features/multifunction/time_calculator_page_test.dart` 锁定。

## 20. 首次启动隐私弹窗与隐私政策

- 首次启动（`privacyAccepted=false`）显示不可取消的隐私弹窗：标题「隐私政策」，正文说明主要功能、本地数据、离线语音与仅汇率联网，并提供「查看完整《隐私政策》」入口；底部按钮「不同意」「同意」。
